# Lexicographically Smallest Permutation via Connected Components

## 1. Problem Definition & Mathematical Formulation
Let $A = (a_1, a_2, \dots, a_n)$ be a sequence of $n$ distinct elements (or a permutation of $\{1, 2, \dots, n\}$). We are provided with a collection of $m$ allowable pairwise transposition operations:
$$\mathcal{S} = \{(u_1, v_1), (u_2, v_2), \dots, (u_m, v_m)\}, \quad u_k, v_k \in \{1, 2, \dots, n\}$$
Applying an operation $(u, v) \in \mathcal{S}$ swaps the elements currently situated at positions $u$ and $v$:
$$\text{swap}(A[u], A[v])$$

Operations in $\mathcal{S}$ may be applied in any sequence and an arbitrary number of times. The objective is to determine the **lexicographically smallest** configuration $A^*$ achievable:
$$A^* = \arg\min_{A' \in \mathcal{O}(A, \mathcal{S})} A'$$
where $\mathcal{O}(A, \mathcal{S})$ denotes the orbit of $A$ under the group action generated by transpositions in $\mathcal{S}$.

---

## 2. Theoretical Analysis & Group-Theoretic Justification

### 2.1 Graph Formulation of Permutation Orbits
Construct an undirected graph $G = (V, E)$ on the index set $V = \{1, 2, \dots, n\}$ where each allowable swap corresponds to an undirected edge:
$$E = \{(u, v) \mid (u, v) \in \mathcal{S}\}$$

By group theory, adjacent transpositions along the edges of any connected component $C \subseteq V$ generate the full symmetric group $\text{Sym}(C)$ acting on the elements located at positions $C$.
- **Theorem**: Elements located at indices in the same connected component $C$ can be rearranged into **any arbitrary permutation** of themselves via a finite sequence of swaps along spanning tree edges of $C$.
- Conversely, elements belonging to distinct connected components cannot exchange positions.

### 2.2 Greedy Minimization Procedure
To make the entire sequence $A^*$ lexicographically minimal:
1. Partition the index set $\{1, 2, \dots, n\}$ into connected components using Disjoint Set Union (DSU) with path compression and union by rank.
2. For each connected component $C = \{i_1, i_2, \dots, i_k\}$ with sorted indices $i_1 < i_2 < \dots < i_k$:
   - Extract the multiset of values residing at these positions:
     $$\mathcal{V}(C) = \{a_{i_1}, a_{i_2}, \dots, a_{i_k}\}$$
   - Sort $\mathcal{V}(C)$ in ascending order:
     $$v_1 \le v_2 \le \dots \le v_k$$
   - Assign $A^*[i_j] \leftarrow v_j$ for all $j \in \{1, \dots, k\}$.

Because $i_1 < i_2 < \dots < i_k$, placing the smallest available value $v_1$ at the earliest available position $i_1$ greedily guarantees global lexicographical optimality.

---

## 3. Complexity Analysis
- **DSU Clustering**: Initializing $n$ sets and processing $m$ swap pairs takes $\mathcal{O}((n + m) \alpha(n))$ time.
- **Component Sorting**: If component $C$ has size $k_C$, sorting both indices and values takes $\mathcal{O}(k_C \log k_C)$.
  Summing across all disjoint components:
  $$\sum_{C} \mathcal{O}(k_C \log k_C) \le \mathcal{O}(n \log n)$$
- **Total Time Complexity**: $\mathcal{O}(m \cdot \alpha(n) + n \log n)$, which is optimal.
- **Auxiliary Space Complexity**: $\mathcal{O}(n)$ for DSU structures and component buckets.
